# Easy Timestamps

Create and manage timestamps for YouTube videos. Built with React, TypeScript, and Tailwind CSS.

## Features

- YouTube video integration
- Timestamp creation and editing
- Dark/Light theme toggle
- Copy timestamps for descriptions
- Responsive design

## Quick Start

```bash
git clone https://github.com/farhanoic/easytimestamps.git
cd easytimestamps
npm install
npm run dev
```

Open `http://localhost:5173`

## Build

```bash
npm run build
```

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- React Player
- Lucide React
- Vite
